# 一、不要重做项目

这是一个已经可以运行的日记网站。

保留：

* React
* TypeScript
* Vite
* React Router
* 现有 API
* 现有数据结构
* 现有页面
* 现有业务逻辑

本次任务主要是 UI / UX 重构。

不要为了做 UI 而重写 backend。

不要修改 API。

不要删除已有功能。

不要制造假数据。

---

# 二、需要实现的视觉效果

整体必须接近 reference/diary-design.png：

关键词：

* 极简
* 冷白
* 蓝灰
* 编辑感
* 私人档案馆
* 安静
* 大量留白
* 细边框
* 低视觉噪音
* 高级但不浮夸

整体颜色：

背景接近冷白色。

主要文字接近深墨黑。

辅助文字使用灰色。

Accent 使用深蓝灰。

整体不要出现：

* 米黄色
* 棕色主色
* 橙色主色
* 紫色主色
* 高饱和渐变
* 彩色背景
* 玻璃拟态
* 大面积阴影

---

# 三、特别重要：不要加入照片

reference/diary-design.png 中原本出现过照片的位置，现在全部取消照片。

不要：

* 添加背景图片
* 添加 banner 图片
* 添加随机照片
* 添加插画
* 添加图片占位符

如果原有功能需要显示图片，也暂时保持纯 UI 布局，不要为了模仿设计稿自行添加图片。

# 四、整体 Layout

Desktop 使用左侧 Sidebar。

Sidebar 是整个网站的固定视觉骨架。

大致结构：

┌────────────┬──────────────────────────────┐
│            │                              │
│  MyDiary   │        Page Content          │
│            │                              │
│  首页      │                              │
│  浏览日记  │                              │
│  过去的今天│                              │
│  随机回忆  │                              │
│  AI 摘要   │                              │
│            │                              │
│            │                              │
└────────────┴──────────────────────────────┘

Sidebar 不要做成传统后台系统的厚重导航。

要非常轻。

当前选中的菜单使用淡蓝灰背景。

---

# 五、首页 HomePage

严格参考图片中的：

「01 首页 - 人生档案馆」

顶部应该有一个非常简洁的品牌区域。

核心视觉：

「我的日记」

下面：

「生活会忘记，但文字记得。」

然后显示统计：

15 个年份
3,284 篇日记
1,821,406 字

数字应该比较突出。

下面是两个主要入口：

过去的今天
随机回忆

不要把首页做成传统 Dashboard。

不要出现：

几十个统计 Card
复杂图表
彩色 KPI
巨大的 Dashboard 标题

首页应该像一个私人档案馆的入口。

---

# 六、浏览日记 BrowsePage

严格参考：

「02 浏览日记 - 时间轴」

核心是：

年份
月份
日期
日记列表

视觉上应该明显体现时间轴。

日期数字比较突出。

每一天是一个轻量级条目，而不是厚重 Card。

支持现有：

* 年份
* 月份
* 类型
* 搜索
* 分页

但是这些功能的视觉样式必须融入设计稿。

搜索框和 Select 都应该非常轻。

---

# 七、日记详情 EntryPage

严格参考：

「03 日记详情 - 沉浸式阅读」

这是最重要的页面之一。

不要让它看起来像：

后台详情页
数据库记录
Markdown 编辑器

应该像：

「一本私人书籍中的一页」

日期：

2026
9 / 17

使用非常大的日期排版。

标题明显。

正文使用舒适的阅读宽度。

正文行高要舒服。

AI 摘要可以作为一个轻量的辅助区域。

底部提供：

上一天
返回列表
下一天

但这些控制都应该非常克制。

---

# 八、过去的今天 OnThisDayPage

严格参考：

「04 过去的今天 - 人生的年轮」

重点不是 Card。

重点是：

同一个日期
不同年份
不同的自己

使用纵向时间线。

例如：

2025
2024
2021
2018

每一年一条。

年份数字突出。

内容简洁。

整体留白非常多。

# 九、随机回忆 RandomPage

严格参考：

「05 随机回忆 - 发现不期而遇的自己」

页面应该非常简单。

中央突出：

2019-06-17

然后：

那一天，你写了 3 篇日记

关于摄影、旅行和生活。

下面一个明显的：

「再来一次」

按钮。

这个页面不要做成随机内容 Dashboard。

它应该有一种「打开一本书，随机翻到一页」的感觉。

严格参考：

「06 AI 摘要 - 用新的视角看自己」

保留现有 AI summary 功能。

视觉重点：

年份
这一年的你

但不要做成企业 BI Dashboard。

不要使用鲜艳颜色。

---

# 十一、Typography

字体必须有层级。

中文正文：

优先系统字体。

例如：

PingFang SC
Noto Sans SC
Microsoft YaHei

英文和数字可以使用：

Inter
system-ui

日期、年份等大型数字可以适当使用 serif 字体。

不要所有文字都是粗体。

不要所有标题都巨大。

---

# 十二、Spacing

宁可留白，也不要塞满。

设计稿最重要的视觉特点之一就是：

「大量留白」。

不要为了提高信息密度而把内容塞满。

页面应该呼吸。

---

# 十三、Card

Card 只能轻量使用。

推荐：

border: 1px solid
border-radius: 8px
极轻阴影或者没有阴影

不要：

border-radius: 24px
巨大阴影
渐变背景
玻璃效果

不是所有内容都应该放进 Card。

---

# 十四、响应式

Desktop 首先做到和设计稿接近。

然后保证：

tablet
mobile

能够正常使用。

Mobile 可以把 Sidebar 变成顶部/底部导航。

但是不要为了响应式破坏 Desktop 设计。

* Border
* Card
* Button
* 蓝灰色 Accent
